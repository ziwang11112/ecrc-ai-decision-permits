# Availability and verification scope

This checkout provides implementation code and compact public evidence.
Larger historical event/database archives are pinned in `ARTIFACTS.json`.
The [result map](RESULTS.md) links current results to their sources.

| Study | In Git | Additional material / boundary |
|---|---|---|

Private transports, model traffic, generated candidates, original SQLite snapshots and private accounting remain author-held. |
| Online shared-budget studies | Actor loop, tools and controller code; primary protocol/schedule; all 1,440 formal scalar projections; statistical reanalysis and current plot code | Original model traffic, generated candidates, private accounting and full execution databases remain author-held. Fresh online use requires a caller-supplied model transport and configured sandbox. |

Public online projections allow numerical reanalysis of every primary and
later provider outcome, including unknown counts and failures. Saved raw-archive
hashes identify author-held originals; their presence is not raw-byte verification.
Offline actor-loop tests use injected model responses and test runners. They are
integration checks and add no trajectories to the scientific results.

Public S9 projections support numerical reanalysis, not verification of omitted
candidate/result bytes. The current 112+32 selection is a correction, not an
independent replication. All 176 original/replacement executions remain indexed.
S11 uses synthetic records and model-free qualification; S12 preserves its prior
failed restart audit. Historical `run_e1.py` source and ten inner calibration
grids remain unavailable and are not reconstructed by this release.

## Integrity and validation

`MANIFEST.json` and `SHA256SUMS.txt` inventory this source revision.
`SOURCE_VIEW.json` separately maps four frozen historical inventories to
included, omitted and overlaid files. New online package manifests distinguish
unchanged source, public adaptations and derived numerical projections.
[ARTIFACT_VALIDATION.json](ARTIFACT_VALIDATION.json) records checks run for
the fixed `code-v1.3.0` release. The additional local checks are recorded in
[REVISION_VALIDATION.json](REVISION_VALIDATION.json). GitHub Actions remain disabled; local validation is not
represented as a hosted CI pass.

Fixed tags and existing assets retain their original contents. Manuscript
text/PDFs/LaTeX and editorial reviews remain outside the active source view.
