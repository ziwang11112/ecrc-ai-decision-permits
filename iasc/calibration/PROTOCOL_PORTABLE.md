# Portable calibration audit: packaging protocol

This is a packaging and reproduction step for the existing 2026-09-11 calibration audit, not a new analysis. Copy the original report, audit JSON, all four CSVs, and original script unchanged into this directory. Copy the frozen predictions, experiment configuration, participant fold assignments, outer and final selected operating points, and the original E1 configuration/routing modules and package initializer. The models module is retained for hash/provenance only; it is not imported or fitted. Preserve source-relative paths and hashes, including their comparison with the original audit's input hashes.

Adapt the audit only to resolve inputs relative to the portable script and to accept `--out` for a new output directory. Refuse to overwrite an output directory. Preserve the grid calculations, routing, threshold eligibility, tie-break ordering, selected-row checks and numeric CSV serialization. The current `run_e1.py` is not a runtime dependency and will not be copied as an asserted original source: record its current hash separately from the incompatible historical E1 manifest hash. Keep the historical code-hash CSV as provenance.

Execute the portable script from a working directory different from its own. Compare the three regenerated core CSVs byte for byte with the originals: `calibration_selected_audit.csv`, `calibration_reconstructed_grids.csv`, and `calibration_grid_summary.csv`. Compare the scientific JSON fields while allowing path/software-provenance additions to differ. The fourth CSV, `calibration_grid_activity.csv`, is preserved as an original ancillary audit output and is not claimed as a direct output of the original three-CSV script.

This script reconstructs only three final-development OOF grids and five history outer-training grids (448 rows) and checks all 15 archived outer selected rows. Ten fitted-model outer-training inner-OOF grids remain unarchived. The algebraic redundancy proof applies under the recorded bounds, but those ten grids are not empirically enumerated. No retraining, threshold adoption/change, frozen-result overwrite, network call or main-manuscript edit is part of this package.
