# Archived plotting source view

The current view retains older plotting code, data, scientific exports and the
complete cap-removal CSV. Document-layout generators, finished LaTeX tables,
bibliography, equation-to-section maps and authored captions are excluded.

`MANIFEST.json` describes the original full release archive. `GIT_MIRROR.json`
describes the earlier selected source view. Their bytes are retained as
historical metadata; the current root `SOURCE_VIEW.json` records omissions
and documentation overlays explicitly.

Use [the current plotting package](../../plots/current/README.md) for compact
CSV-based reconstruction. To execute these older builders with their copied
database evidence, use the complete S1–S8 archive described in the
[reproducibility guide](../../REPRODUCIBILITY.md).
