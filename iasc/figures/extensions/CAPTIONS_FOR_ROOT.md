# Suggested captions and integration notes

Figure 4:

Runtime validation using archived fault and contention records and an independent semantic validator. (a) Detected/injected fault counts. The four archived validators passed 32 clean controls; the independent validator accepted one complete clean trace containing 32 permits and 32 receipts. The independent validator receives the same trusted state and performs offline detection; these counts do not establish external effect prevention. (b) Capacity-bearing routes admitted (points) and configured limits (horizontal marks); labels give admitted/limit counts. The race witness is the forced non-atomic case. (c) End-to-end 95th-percentile (p95) latency: median and minimum–maximum range across three repetitions at each worker count. These ranges are not confidence intervals; effects are simulated within one SQLite ledger.

Figure 5:

Candidate-set discrimination and budget-matched online allocation. Dev denotes development; HGB denotes histogram gradient boosting; AUROC denotes area under the receiver operating characteristic curve; FIFO denotes first-in, first-out allocation. Rows identify the same cohort and generator across panels. (a) Discordant-pair-weighted within-participant AUROC among alert candidates, with conditional 95% participant-cluster intervals; parentheses give the number of participants with both candidate classes. The dashed 0.5 reference is descriptive. (b,c) Pacing minus FIFO changes in alert precision and proxy-positive alert coverage. Filled points use eight units per episode; open points use ceiling(8H/100) with the protocol-defined planned horizon H. Bars are paired conditional 95% participant-cluster intervals, and zero lines mark no difference. Online analyses include all 617 development and 59 external participants. These are post hoc analyses of frozen scores and operating points. Data sources: Steingroever et al. [steingroever2015manylabs] and Mendeley Data Version 2 [chavez2026dataset]; horizon protocols additionally use [chavez2026behavioral].
