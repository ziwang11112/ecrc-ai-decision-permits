# Browsable original S9 and current S9-C sources

The current corrected analysis and public verification entry point are in
[context_correction/README.md](context_correction/README.md). It combines 112
retained original runs with 32 predetermined replacement runs. The original
`analysis/` tables and documentation in this directory remain historical;
all 144 original runs, including the superseded 32, remain available.

This Git directory contains the application/runner/client source, frozen
protocol, catalog metadata, analysis and plotting code, all numerical tables,
licence notices and independent audit summaries. The full result projections
and their manifests are in the fixed release ZIP, not duplicated in Git.

Download AIR-014_IASC_S9_Code_and_Results.zip and its SHA256SUMS from
https://github.com/ziwang11112/ecrc-ai-decision-permits/releases/tag/iasc-application-2026-09-12
and extract the AIR-014_IASC_S9 directory before running check_public.py.
PUBLIC_INVENTORY.json describes that complete release bundle, including its
results/ directory. It is not an inventory of this intentionally smaller Git
source view. Read README.md and FINAL_RESULTS.md for historical protocol, results and
candidate-source reconstruction and redistribution boundaries.
